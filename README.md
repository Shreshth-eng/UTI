# 🚚 UTI - Unified Transport Interface

UTI (Unified Transport Interface) is a web-based platform developed to simplify the communication between customers, companies, truck owners, and drivers. The main goal of this project is to bring all the stakeholders involved in transportation onto a single platform, making the logistics process more organized and efficient.

This project was built as a hackathon idea to address common problems in the transport industry, where finding available trucks, coordinating with drivers, and managing shipments often takes a lot of time and manual effort.

---

## Why We Built This

In many cases, people who need to transport goods have to contact multiple transport providers before finding an available truck. At the same time, truck owners may have idle vehicles because they are unable to connect with customers efficiently.

We wanted to create a single platform where customers, companies, truck owners, and drivers can interact without unnecessary delays and confusion.

---

# What the Platform Does

- Allows different types of users to register and log in.
- Customers can create transport requests.
- Truck owners can register their trucks.
- Companies can manage transportation requirements.
- Drivers can receive assigned deliveries.
- Shipment details can be viewed and updated through the platform.

# How to Run the Project

# Clone the repository

```bash
git clone https://github.com/yourusername/UTI.git
```

# Install frontend dependencies

```bash
cd frontend
npm install
npm run dev
```

# Install backend dependencies

```bash
cd ../backend
npm install
npm start
```
